Proyek ini menggunakan OpenCV untuk pengenalan Jari dan Tangan. Sistem ini dibuat berdasarkan ide saya untuk membuat sistem kontrol servo menggunakan teknologi computer vision.Yang di integrasikan kedalam sebuah realtime database (FIREBASE) untuk mencatat kontrol derajat servo.Sistem ini masih memerlukan banyak perkembangan agar dapat berjalan lebih baik dan layak digunakan sebagai sebuah sarana pendidikan
<hr>
<h2 align="center">CARA PENGGUNAAN</h2>
<ul>
  <li>=> <strong>Membutuhkan python 3.11.</strong></li>
  <li>=> Buat Akun firebase dan buat sebuah realtime database</li>
  <li>=> pergi ke Settings > ServiceAccount > buat service account dan download dalam file .json</li>
  <li>=> masukkan database url di file visi.py</li>
  <li>=> Clone / Copy semua file && direktori github (https://github.com/fadlannn69/AI-SERVO-CONTROLLER.git)</li>
  <li>=> buat sebuah virtual environment (venv)</li>
  <li>=> aktivasi virtual environment Linux(source venv/bin/activate) Windows(source venv/Scripts/activate)</li>
  <li>=> Install semua yang ada di file .[requirements.txt](requirements.txt) (python3 pip install -r requirements.txt)</li>
  <li>=> Jalankan (python3 visi.py)</li>
</ul>
